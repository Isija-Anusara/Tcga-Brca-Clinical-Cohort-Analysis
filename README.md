* TCGA-BRCA Clinical Cohort Stratification
  This is a python script for parsing data and also for the clinical cohort stratification pipeline analysing

  * Dataset
    Source - TCGA Breast Invasive Carcinoma 

  *The way to run this
  Download the file from https://www.cbioportal.org/study/summary?id=brca_tcga and extract it
  Then, search and data_clinical_patient.txt file and upload it to Google Collab or VS code
  Place it there and run the script
